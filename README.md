<h2 data-importer="text" align="left">Featured Projects</h2>

###

### 🏊 [PoolCare AI](https://github.com/ElRichi-SA/PoolCare-AI-Agent)

An AI-powered web assistant for pool water analysis and maintenance. Combines **business rules, retrieval-augmented generation (RAG), and Google Gemini** to provide diagnostics, treatment guidance, and chemical dosage calculations.

**Built with:** Python, FastAPI, LangChain, FAISS, Gemini, HTML, CSS, JavaScript, Bootstrap.

> Source code and project documentation are available in the repository. The live demo is currently offline.

### 🏥 [MediFlow](https://github.com/No-Country-simulation/G10-MediFlow-Team11)

A collaborative medical document processing project developed during a hackathon. I contributed to the **frontend**, including project setup, routing, UI foundations, and TypeScript data models.

**Built with:** React, TypeScript, Vite, Material UI, React Router, Git & GitHub.
